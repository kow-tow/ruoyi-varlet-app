# ruoyi-varlet-app

企业级原型脱敏披露版

## Install Dependencies

```shell
pnpm install
```

## Start the development environment

```shell
pnpm dev
```

## Build

```shell
pnpm build
```

## Preview

```shell
pnpm preview
```

## Lint Code

```shell
pnpm lint
```

## TS type checking

```shell
pnpm type-check
```

## Code Formatting

```shell
pnpm format
```
